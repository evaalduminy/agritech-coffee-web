# AgriMarket | منصة التسويق الزراعي الذكية
### Smart Agricultural Marketplace

منصة تجارة وتسويق زراعية رقمية متكاملة تربط المزارعين والمنتجين المحليين مباشرة بالمشترين ورواد الأعمال، متخصصة في المحاصيل الزراعية الفاخرة وفي طليعتها محاصيل البن اليمني الأصيل، بنقاء نكهات فريد وتوريد طازج مباشر وموثق بدون وسطاء.

---

## الرؤية والأهداف

تهدف منصة **AgriMarket** إلى تمكين المنتجين والمزارعين المحليين من الوصول المباشر إلى الأسواق والمشترين المعتمدين، مع توفير شفافية كاملة في سلاسل الإمداد وتوثيق مواصفات المحاصيل ومصادرها الجغرافية. تعتمد المنصة نموذج تواصل مباشر وتوثيق للحجوزات والطلبات عبر الربط البرمجي مع خادم واجهة التطبيقات (Laravel REST API) والتنسيق الميداني المباشر عبر واتساب، متجاوزة تعقيدات ورسوم بوابات الدفع الإلكتروني التقليدية لتسهيل المعاملات العادلة بين المزارع والمشتري.

---

## أبرز مميزات المنصة

- **نموذج تجارة مباشر وموثق:** ربط مباشر للمحاصيل بالمزارع والمدرجات المنتجة، مع توثيق الطلبات والحجوزات مسبقاً وتأكيدها عبر واتساب مع ممثلي المنصة والمزارعين.
- **عقد طلب مبسط وموثوق (v1 Contract):** اعتماد كمية الطلب وحقل الملاحظات الاختيارية (حتى 1000 حرف) لتعليمات التوريد والتسليم، مع احتساب شفاف ودقيق للإجمالي.
- **نظام ثنائي للتشغيل (Dual-Mode Architecture):**
  - **الوضع الحي (Live API Mode):** اتصال مباشر مع خادم Laravel عبر Sanctum للمصادقة وإدارة الطلبات والمنتجات والإعدادات.
  - **وضع المحاكاة التفاعلية (Mock Mode):** بيئة تجريبية متكاملة ومستقلة تتيح تجربة كافة خصائص المنصة دون الحاجة لخادم خلفي محلي.
- **خلفيات بصرية وتفاعلات متقدمة:** خيارات متعددة لتخصيص الواجهة تشمل جزيئات الكانفاس الفيزيائية التفاعلية (Interactive Particles)، والتوهج العضوي الناعم (Organic Ambient)، والخلفية المبسطة الهادئة.
- **نظام إعدادات وهوية متكامل (Settings Drawer):**
  - دعم الوضعين النهاري والليلي (Light / Dark Mode).
  - ثلاثة أنساق لونية قابلة للتخصيص: الأخضر الزراعي المعتمد (AgriTech)، البن المحمص والذهبي (Roasted)، والفحمي الكلاسيكي (Obsidian).
  - تخصيص أشكال الأزرار (انسيابي ناعم، كبسولة دائرية، حاد هندسي).
  - تخصيص أنماط مؤشر الانتقال وشاشة التحميل.
- **دعم ثنائي كامل للغة والاتجاه (Bilingual & RTL/LTR):** واجهة عربية أصيلة واتجاه `dir="rtl"` مع دعم كامل وموازي للغة الإنجليزية والاتجاه `dir="ltr"`.
- **لوحة تحكم المشتري المعتمد (Buyer Dashboard):** إدارة سجل الطلبات والحجوزات السابقة، متابعة الحالات، وتحديث بيانات التوصيل والتواصل.
- **بوابة خدمة المزارعين (Farmers Portal):** نافذة تواصل مباشرة لخدمة وتوثيق المزارع والتعاونيات الزراعية الميدانية.
- **جاهزية النشر السحابي (Vercel Ready):** تكوين مدمج لإعادة التوجيه (`vercel.json`) لضمان استقرار مسارات SPA عند الرفع المباشر.

## حزمة التقنيات المستخدمة (Tech Stack)

- **بيئة العمل الأساسية:** React 19, Vite 8
- **التصميم وتنسيق الواجهات:** Tailwind CSS, PostCSS, Autoprefixer
- **الحركات والتأثيرات التفاعلية:** Framer Motion, HTML5 Canvas API, Three.js
- **الأيقونات:** Lucide React
- **الاتصال بالخادم:** Axios, Fetch API (Laravel Sanctum Integration)
- **المصادقة السريعة:** Firebase Auth (اختياري في وضع المحاكاة)
- **الخطوط:** Cairo Font (Google Fonts)

## هيكل مجلدات المشروع

```text
src/
├── assets/             # الصور والأصول البصرية الثابتة
├── components/
│   ├── common/         # العناصر العامة والشعار والأزرار العائمة
│   ├── home/           # مكونات الصفحة الرئيسية (Hero, الفلاتر, شبكة المحاصيل, آراء العملاء)
│   ├── layout/         # الشريط العلوي (Navbar), التذييل (Footer), وشاشات الانتقال
│   └── modals/         # نوافذ السلة (CartDrawer), تفاصيل المحصول, الإعدادات, والمصادقة
├── config/             # ملف الإعدادات المركزي ومصدر الحقيقة الموحد (siteConfig.js)
├── context/            # سياقات الحالة (CartContext, AuthContext, SettingsContext)
├── data/               # البيانات التجريبية وقاموس الترجمة الموحد (translations.js)
├── pages/              # الصفحة الرئيسية (HomePage) ولوحة المشتري (BuyerDashboard)
└── services/           # خدمات الاتصال بخادم Laravel (api.js) ومولد روابط واتساب (whatsapp.js)
```

## التشغيل والتطوير المحلي

### المتطلبات المسبقة:
- Node.js (الإصدار 18 أو أحدث)
- مدير الحزم npm

### خطوات التثبيت والتشغيل:

1. استنساخ المستودع:
```bash
git clone https://github.com/hevasaleh64-sys/agritech-coffee-web.git
cd agritech-coffee-web
```

2. تثبيت الحزم:
```bash
npm install
```

3. ضبط متغيرات البيئة (اختياري للوضع الحي مع Laravel):
أنشئ ملف `.env` في جذر المشروع:
```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
VITE_USE_MOCK_API=false
```
*(ملاحظة: إذا تُرك المتغير غير محدد أو أُسندت له القيمة `true`، ستعمل المنصة تلقائياً بوضع المحاكاة الكامل لسهولة المعاينة)*.

4. تشغيل سيرفر التطوير المحلي:
```bash
npm run dev
```

5. فحص الكود وبناء النسخة الإنتاجية:
```bash
npm run lint
npm run build
```

6. معاينة نسخة الإنتاج محلياً:
```bash
npm run preview
```

## النشر السحابي (Vercel)

المشروع مزود بملف `vercel.json` لإعادة توجيه كافة المسارات نحو `index.html`. عند استيراد المشروع في لوحة تحكم Vercel، يمكنك إسناد `VITE_USE_MOCK_API=true` في متغيرات البيئة ليعمل الموقع كمعاينة تفاعلية متكاملة على السحابة دون الحاجة لخادم محلي.
