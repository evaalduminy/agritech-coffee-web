# الدليل الهندسي والتعليمي الشامل لمنصة AgriMarket
# Comprehensive Engineering & Architecture Guide

مرحباً بكِ في المرجع المعماري والتعليمي الشامل لمنصة **AgriMarket**. صُمم هذا الدليل ليكون مرجعكِ الدائم لفهم أدق تفاصيل الكود، البنية الهندسية، أسرار التصميم والأنيميشن، وطريقة التعديل الذاتي السريع دون الحاجة للاعتماد على أي طرف خارجي.

---

## فهرس ملفات الدليل (Guide Index)

يتألف الدليل من 4 وثائق هندسية متخصصة ومترابطة:

### 1. [الهيكلية وخريطة الملفات وتدفق البيانات](01_ARCHITECTURE_AND_FILES.md)
- **محتوى الملف**:
  - رسم الشجرة الكاملة لجميع مجلدات وملفات المشروع الفعلية داخل `src/`.
  - جدول تفصيلي يوضح وظيفة كل ملف فعلي وأهم الصادرات والدوال بداخله.
  - مخطط تدفق البيانات (Data Flow) بين المكونات الجذعية وسياقات الحالة (`AuthContext`, `CartContext`, `SettingsContext`) وطبقة الـ API.
  - شرح معمارية التبديل السلس بين الوضع التجريبي والحي (`Mock / Live Switch`).
  - هندسة سلم الـ `z-index` وكيف تحل بوابات `createPortal` مشكلة تداخل النوافذ مع الشريط العلوي.

---

### 2. [دليل التصميم والأنيميشن ونظام الحركة](02_DESIGN_AND_ANIMATIONS.md)
- **محتوى الملف**:
  - شرح نظام ألوان الهوية الترابية الزمردية (`Terrace Earth`) ورموز Tailwind المخصصة.
  - آلية عمل الوضع الليلي والنهاري (`dark:`) والتجاوز السلس للمتغيرات في `index.css`.
  - تشريح تأثير الزجاج المصنفر (`Glassmorphism`) وشرح كل فئة Tailwind مسؤولة عنه.
  - شرح تفصيلي لجميع حركات المنصة بمقتطفات كود حقيقية:
    - الخلفية التفاعلية والجزيئات الفيزيائية وهالة الضوء في `GlobalInteractiveBackground`.
    - دوران مجسم الهاتف ثلاثي الأبعاد والزر المغناطيسي في `Hero.jsx`.
    - الظهور التسلسلي للبطاقات في المتجر (`stagger`) ومنحنى السرعة المخصص `ease: [0.22, 1, 0.36, 1]`.
    - أنيميشن طيران المنتج نحو السلة وحساب الإحداثيات في `FlyToCartOverlay`.
    - انزلاق القوائم الجانبية ومراعاة الاتجاهين العربي والإنجليزي (`RTL / LTR`).
  - جدول الأرقام السريعة لتسريع أو تبطيء أو تعطيل أي حركة في لحظات.

---

### 3. [كتاب الطبخ للتعديل السريع بنفسي وحل المشكلات](03_EDITING_COOKBOOK.md)
- **محتوى الملف**:
  - جدول عملي بصيغة: **"إذا أردتِ تعديل X ← افتحي الملف Y ← ابحثي عن Z ← انتبهي لعدم كسر W"**.
  - سيناريوهات تغطي:
    - تعديل النصوص، الرسائل، وقسم الأسئلة الشائعة (FAQ).
    - تعديل اسم الشعار، السطر الفرعي، وأبعاد اللوجو في `BrandLogo.jsx`.
    - تغيير أرقام هواتف الواتساب، ساعات العمل، وبيانات التواصل.
    - تعديل شكل بطاقة المنتج وعناصرها.
    - إضافة قسم جديد في الصفحة الرئيسية أو إعادة ترتيب الأقسام.
    - تعديل الألوان، الشفافية، ومسارات الـ API الجديدة.
  - قسم تفصيلي لأشهر 5 أخطاء قد تحدث عند التعديل اليدوي وكيفية حلها في دقائق.

---

### 4. [دليل المهارات والأنماط الهندسية ووصفة المشاريع الجديدة](04_REUSABLE_PLAYBOOK.md)
- **محتوى الملف**:
  - قائمة بالأنماط البرمجية (Design Patterns) المطبقة في المشروع (العزل، التطوير الموجه بالعقود، تنقية الحمولات، محرك التشغيل المزدوج، وإدارة الحالة المركزة).
  - وصفة متكاملة خطوة بخطوة لبدء أي مشروع React جديد من الصفر (`Starter Blueprint`).
  - هيكلية مجلدات احترافية جاهزة للنسخ المباشر.
  - قالب دستور قواعد الكود النظيف (`PROJECT_RULES.md`) القابل لإعادة الاستخدام في أي مشروع مستقبلي لضمان نفس معايير السرعة والنظافة البرمجية.
